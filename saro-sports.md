## Privacy Policy Document for the App `Saro Sports`


App Introduction
----------------

`Saro Sports` is a Mobile Application launched for Sports Enthusiasts to register for tournaments in their
geography. Get notified about the matches. Then the tournament organiser will have scoring team to 
update live scores in the app so that all the viewers are able to view the scores live in the app.

This application specifically targets users of age between 15 and above.


What Data we collect?
---------------------

This application collects the `mobile number` and `name` of the users.
Additionally for Organiser users, the app collects the Government Id number & a file attachment
representing the proof of the given Id.

The app stores these in the app's server database to customize the application content based on the
user credentials.


Data Safety
-----------

The security of the Application users is our top most concern. Such collected information
is encrypted and sent to server application using a properly signed SSL certificate ensuring
at most information security.

Is your data shared to anyone?
------------------------------

Not at all! We dont share anything. The above Information collected by this app are NOT shared
with or sold to any other person or company or organization for any purpose.

This app DOES NOT USE any 3rd party libraries or services that needs the personal information
of its users.

Your Data Deletion
------------------

If you want all your data to be deleted from this app, please send an E-Mail to 
`saravanansportsmgmt@gmail.com` along with your username. Don't send any passwords to us.
We will shortly have a web based interface using which, you will be able to trigger deletion of
data directly without needing this E-Mail process.
